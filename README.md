# Wole-AI-ML-Challenge
A structured 30-day challenge as a progressive AI/ML portfolio challenge, moving from data
understanding and Python fundamentals through EDA, preprocessing, supervised learning, model
evaluation, explainability, and finally deployment/presentation.

Datasets to be used
1. Student Performance — student-por.xlsx
o 649 student records
o Variables include demographics, family background, study time, failures,
absences, G1/G2/G3 grades, etc.
o Main project: Student Performance Prediction
2. Nigeria House Prices — nigeria_houses_data.csv
o 24,326 property records
o 8 variables: bedrooms, bathrooms, toilets, parking space, title, town, state and
price.
o Main project: Nigeria House Price Prediction
3. Stroke Disease — StrokeDisease.csv
o 5,110 records
o 12 variables including age, hypertension, heart disease, glucose level, BMI,
smoking status and stroke outcome.
o Main project: Stroke Risk Classification
